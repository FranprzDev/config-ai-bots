# Skills

Portable skill docs I used with my previous assistant. Each folder has a `SKILL.md` with a small front matter (`name`, `description`) so it works as an Agent Skill (e.g. Claude Code `.claude/skills/`, OpenCode, Codex) or can simply be pasted into a project's instructions.

| Skill | Use it when |
|---|---|
| [`franprzdev-code-conventions`](franprzdev-code-conventions/SKILL.md) | Writing, reviewing or merging code in my repos (types, style, PR hygiene, merge rules). |
| [`ponytail`](ponytail/SKILL.md) | Any coding task: the smallest complete change, "lazy senior developer" (MIT, adapted). |
| [`tailored-cv-apply`](tailored-cv-apply/SKILL.md) | Any job application that takes a CV: one-page CV tailored per posting, critique and honesty check. |
| [`premium-scroll-pages`](premium-scroll-pages/SKILL.md) | Landing pages or scroll sites that must not look like "AI slop". |
| [`cinematic-shot`](cinematic-shot/SKILL.md) | Directing a cinematic product launch video from real UI. |
